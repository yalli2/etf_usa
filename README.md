# ETF USA 국면 노트

미국 배당 ETF 선별, 시장 국면(Bull/Bear) 판단, 분할매수·분할매도 계획을 한 화면에서 만드는 인터랙티브 사이트입니다.

- 1단계: S&P 500의 200일선·50일선·VIX·고점 대비 낙폭으로 국면 점수 계산, Bull·Bear ETF 선택기
- 2단계: 배당 ETF 11개를 여섯 지표로 점수화 (가중치 조절 가능)
- 3단계: 코어–위성 포트폴리오 구성과 예상 배당
- 4·5단계: 분할매수·분할매도 계획표 (체결 표시는 브라우저에 저장)
- 부록: 레버리지 ETF 변동성 손실 시뮬레이션

데이터 기준일은 2026-11-10 미국장 종가 전후이며 `index.html` 안의 `DATA` 객체에서 수정할 수 있습니다.
이 사이트는 주문을 실행하지 않으며 투자 자문이 아닙니다.
